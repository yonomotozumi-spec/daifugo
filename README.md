# 大富豪（大貧民）

ブラウザだけで遊べる大富豪です。CPU 3 人と対戦できます。
ビルド不要・依存パッケージなしの素の HTML + ES Modules なので、`index.html` を開けばそのまま動きます。

```
git clone https://github.com/yonomotozumi-spec/daifugo.git
cd daifugo
npx --yes http-server . -p 8080   # または python3 -m http.server 8080
# → http://localhost:8080 を開く
```

ES Modules を使っているため、`file://` で直接開くとブラウザに読み込みを拒否されます。
上のように簡易サーバー経由で開いてください。

同じリポジトリに、もう 3 つのゲームが入っています。画面右上のリンクで行き来できます。

- **[テキサスホールデム](poker/)**（`http://localhost:8080/poker/`）— CPU 3 人とのノーリミット・ポーカー → [遊びかた](#テキサスホールデムポーカー)
- **[のんびり釣り日和](fishing/)**（`http://localhost:8080/fishing/`）— スマホではホーム画面に追加してアプリとして遊べます → [遊びかた](#のんびり釣り日和釣りゲーム)
- **[戦国 天下統一](sengoku/)**（`http://localhost:8080/sengoku/`）— 1560 年の日本で大名を選び、内政・合戦・外交で天下を目指す歴史シミュレーション → [遊びかた](#戦国-天下統一歴史シミュレーション)

## 遊びかた

- カードをクリックして選び、**出す**。出せないときは **パス**。
- **ヒント** を押すと CPU と同じ思考ルーチンがおすすめの手を選んでくれます。
- 右上の **ルール設定** → **初期設定に戻す** で、ルール・ゲームの長さ・ポイントを最初の状態に戻せます。
- キーボード：`Enter` で出す、`P` でパス、`Esc` で選択解除。
- 3 人があがった時点でラウンド終了。大富豪 3pt / 富豪 2pt / 貧民 1pt / 大貧民 0pt が加算されます。
- **決めたラウンド数を戦い終えると、合計ポイントで総合順位と優勝者が決まります。**
  長さは右上の **ルール設定** から 3 / 5 / 10 ラウンドで選べます（既定は 5）。
  同点のときは大富豪を多く取ったほうが上、それも並べば同順位です。

## 対応しているルール

右上の **ルール設定** から個別に ON / OFF できます（設定はブラウザに保存されます）。

| ルール | 内容 |
| --- | --- |
| 革命 | 同ランク 4 枚、または 5 枚以上の階段で強さが逆転する。もう一度出せば元に戻る |
| 8 切り | 8 を含む手を出すと場が流れ、同じ人がそのまま親になる |
| 縛り | 同じスートが 2 回続くと、その場はそのスートしか出せなくなる |
| 階段 | 同じスートの 3 枚以上の連番を出せる |
| スペ3返し | ジョーカー 1 枚に対して ♠3 で勝てる |
| カード交換 | 2 ラウンド目以降、大富豪⇔大貧民で 2 枚、富豪⇔貧民で 1 枚を交換する |

その他の基本ルール:

- カードの強さは 3 < 4 < … < K < A < 2 < ジョーカー。
- ジョーカーはワイルドカードとして、同ランクの組にも階段の穴埋めにも使えます。
  ただし階段の**両端**には使えません（5-6-7 とも 6-7-8 とも読めてしまうため）。
- 場が空のときはパスできません。全員がパスすると場が流れ、最後に出した人が親になります。
- 初回の親は ♦3 を持っている人、2 ラウンド目以降は前回の大貧民です。

未実装のルール：都落ち、反則あがり、ジョーカー 2 枚出しの特別扱い、5 人以上での対戦。

## 構成

```
index.html          画面のマークアップ
src/engine.js       ルールエンジン（DOM 非依存。Node からも読める）
src/match.js        ポイント集計と総合順位（DOM 非依存）
src/ai.js           CPU の思考ルーチン
src/ui.js           描画とイベント処理
src/style.css       スタイル
test/engine.test.js エンジンの単体テスト（node:test、依存なし）
test/match.test.js  ポイント集計と総合順位のテスト
test/browser.smoke.mjs 実ブラウザでの通し確認（Playwright、任意）
```

ルール判定は `src/engine.js` に閉じています。役の解釈は `parseCombo()`、
場に出せるかの判定は `canPlay()`、進行は `Game` クラスが持っています。
乱数は差し替え可能（`new Game({ rng })`）なので、シードを固定すれば同じ配牌を再現できます。

## テキサスホールデム（ポーカー）

`poker/` にあるノーリミット・テキサスホールデムです。CPU 3 人と、どちらかが全部のチップを
取るまで戦います。→ [poker/](poker/)

### 遊びかた

- 手札 2 枚と場の 5 枚（フロップ 3・ターン 1・リバー 1）から、いちばん強い 5 枚を作ります。
- 各ストリートで **フォールド / チェック・コール / ベット・レイズ** を選びます。
  レイズは「レイズ」を押すとスライダーが開き、1/2 ポット・3/4 ポット・ポット・オールインの
  プリセットからも選べます。
- **ヒント** を押すと、CPU と同じ思考で「いまの勝率」とおすすめのアクションを教えてくれます。
- キーボード：`F` でフォールド、`C` でチェック／コール、`R` でレイズ。
- 自分の手札の下には、いまの役（プリフロップならポケットの形）が常に出ています。

### ルール

- ノーリミット。ミニマムレイズ（直前のレイズ幅以上）を満たさない額は自動で最低額まで引き上げます。
- 誰にもコールできない額は積めないよう、相手の最大額でレイズの上限を止めています。
- オールインが絡むとメインポットとサイドポットに分かれ、拠出額に届いていない人は
  上のポットを取れません。引き分けは山分けし、端数はボタンの左隣から 1 枚ずつ配ります。
- ブラインドはヘッズアップになるとボタンが SB になります。
- 設定から持ちチップ（5,000 / 10,000 / 20,000）、ブラインド、ブラインドの上昇間隔を選べます。

### CPU

3 人はそれぞれ **タイト / バランス / ルース** の性格を持っています。
毎回モンテカルロで自分の勝率を見積もり（プリフロップ 300 回、フロップ以降 500 回）、
ポットオッズと突き合わせて降りる・コールする・レイズするを決めます。
性格ごとに強気さ・ブラフ頻度・降り際のマージンが違うので、3 人が同じ打ち方にはなりません。

### 構成

```
poker/index.html          画面のマークアップ
poker/src/hand.js         役の判定（7 枚から最強の 5 枚を選ぶ）
poker/src/engine.js       ベッティングの進行・サイドポット・ショーダウン
poker/src/ai.js           勝率のモンテカルロ推定と着手の決定
poker/src/ui.js           描画とイベント処理
poker/src/style.css       スタイル
poker/test/hand.test.js   役判定のテスト
poker/test/engine.test.js 進行・ポット・ショーダウンのテスト
```

役の強さは `evaluate()` がひとつの整数に畳んで返すので、比較は数値の大小だけで済みます。
乱数は差し替え可能（`new Table({ rng })`）なので、シードを固定すれば同じ配牌を再現できます。

## のんびり釣り日和（釣りゲーム）

`fishing/index.html` を開くと遊べます。魚を釣って売り、そのお金で竿・ルアー・釣り場を買いそろえていくゲームです。
大富豪とは独立していて、こちらもビルド不要・依存パッケージなしです。

### 流れ

1. **キャスト** して、ウキが沈むのを待つ
2. アタリが来たら **合わせる**（早すぎても遅すぎても逃げられます）
3. **寄せのミニゲーム**：長押しで寄せバーを上げ、離すと落ちる。魚をバーに入れ続けると寄ってくる
4. 釣れたら **売る** か **逃がす**（逃がしても図鑑の記録は残ります）
5. 貯めたお金でショップから道具を買い、もっと大物が釣れる釣り場へ

操作はスペースキー（キャスト／合わせ／長押しで巻く／売る）、`S` でショップ、`Z` で図鑑。
画面のどこをクリック・タップしても同じように操作できます。所持金と図鑑はブラウザに保存されます。

### スマホ・タブレットで遊ぶ（アプリとして追加する）

ブラウザで開いてホーム画面に追加すると、アドレスバーのない全画面のアプリとして起動します。
ストアからの入手は不要で、**通信が切れても遊べます**（釣果もそのまま残ります）。

- **iPhone / iPad（Safari）**：共有ボタン → 「ホーム画面に追加」。
  画面右上の <kbd>⬇️</kbd> を押すと、この手順が絵つきで出ます。
- **Android（Chrome）**：右上の <kbd>⬇️</kbd>、またはブラウザの「アプリをインストール」から。
- **PC（Chrome / Edge）**：アドレスバーのインストールアイコンから。

縦持ち・横持ち・タブレットのどれでも遊べるように組んでいます。

| 端末 | 画面 |
| --- | --- |
| スマホ（縦） | 釣り場が画面いっぱい。日誌は下から引き出す。所持金と釣り場だけ上に出す |
| スマホ（横） | 操作部を薄くして釣り場を広く取る |
| タブレット・PC | 右側に釣果と釣り日誌を並べた 2 段組 |

操作はすべて指だけで完結します（画面のどこでもタップでキャスト／合わせ、長押しで巻き上げ）。
アタリ・釣り上げ・ライン切れでは、対応する端末なら手元も震えます。

### そろえるもの

| 種類 | 内容 |
| --- | --- |
| 釣り竿 | パワー・寄せ速度・バーの広さ・ライン強度が上がる。竿より強い魚を掛けるとラインが切れる |
| ルアー・エサ | レアな魚の出やすさ、アタリの速さ、ゴミの釣れにくさが変わる。釣り場ごとの得意・不得意もある |
| 道具 | 買い切りの補助アイテム 10 種。買った時点からずっと効き、効果は重ねがけできる |
| お札 | 使い切りのアイテム 5 種。何枚でも買え、使うと数投のあいだ効く |
| 釣り場 | 池 → 渓流 → 漁港 → 氷上の湖 → 海 → 南の島 → 地底湖 → 深海 の 8 か所。奥ほど高い魚が出る |

道具は付け替えがなく、買うだけで効きます（クーラーボックスで売値 +12%、タモ網で逃げられにくい、
偏光グラスで合わせの猶予が伸びる、電動リールで寄せが速くなる、魚群探知機でゴミを避ける、
大漁祈願のお守りでレアが出やすくなる…など）。ショップの「道具」タブに、
いま効いている合計が出ます。

魚は全 79 種。レア度は ふつう / めずらしい / レア / 超レア / 伝説 の 5 段階で、
同じ魚でも大きいほど高く売れます。キャストするたびに 朝 → 昼 → 夕 → 夜 と時間が進み、
夜ほどレアが出やすくなります。

釣り場はどこも 9〜11 種の魚がいて、それぞれに伝説の 1 匹（池の主、カッパの皿、黄金のクロダイ、
シロチョウザメ、クロカジキ、ジンベエザメ、地底湖のヌシ、シーラカンス）が隠れています。
新しい釣り場に手が届くと、ショップのボタンに印がついて日誌でも知らせます。

### ヌシ（ボス）

釣り場ごとに 1 体、二つ名を持ったヌシがいます。**半分まで寄せると本気を出して**、
速く・逃げ足も強くなります。強い竿と道具がないとラインを切られます。

| 釣り場 | ヌシ | 二つ名 |
| --- | --- | --- |
| 池 | 🐉 池の主 | 沼の古老 |
| 渓流 | 🥏 カッパの皿 | 川の悪戯 |
| 漁港 | ✨ 黄金のクロダイ | 堤防の主 |
| 氷上の湖 | 🐊 シロチョウザメ | 氷底の帝王 |
| 海 | 🗡️ クロカジキ | 海の弾丸 |
| 南の島 | 🦈 ジンベエザメ | 青の巨神 |
| 地底湖 | 🐲 地底湖のヌシ | 闇を統べるもの |
| 深海 | 🐊 シーラカンス | 太古の生き証人 |

ふだんは滅多に掛かりませんが、**ヌシの札**を使うとその釣り場のヌシを狙えます。

### お札（使い切り）

ためたお金の使いどころです。ショップの「お札」タブで何枚でも買えます。

| お札 | 値段 | 効果 |
| --- | ---: | --- |
| 🍡 撒き餌の玉 | 800円 | 次の 1 投：アタリがすぐ来る |
| 🍀 幸運の札 | 5,000円 | 次の 1 投：レアが出やすい |
| 🧷 安全ピンの札 | 6,000円 | 次の 1 投：ラインが切れない |
| 🌟 時合いの札 | 9,000円 | 5 投のあいだ大漁タイム |
| 👑 ヌシの札 | 25,000円 | 次の 1 投：ヌシが出やすい（レア以上が確定） |

### はじめからやり直す

釣り日誌の下（スマホでは 📋 の引き出しの下）にある **🗑️ はじめから** から、
この端末に保存された釣りの記録を消して最初の状態に戻せます。
押すと「何が消えるか」を並べた確認が出るので、うっかり消してしまうことはありません。
大富豪の成績とは別のデータなので、そちらには影響しません。

（大富豪のほうは、総合結果の **もう一度あそぶ** でポイントが 0 に戻ります。
ルール設定の **初期設定に戻す** を押せば、ルールとゲームの長さも既定に戻ります。）

### 天気とできごと

天気は数投ごとに変わり、釣果にも影響します。

| 天気 | 効果 |
| --- | --- |
| ☀️ 晴れ | おだやかな一日 |
| ☁️ くもり | 魚の警戒がゆるむ（アタリ +10%、レア +6%） |
| 🌧️ 雨 | アタリが増える（+25%）。少し大物寄り |
| 🌫️ 霧 | 珍しい魚が寄る（レア +30%）。アタリは少し遠のく |
| ⛈️ 嵐 | 大物が動く（レア +40%）。ラインへの負荷が 1.6 倍になり切れやすい |

釣りの最中には、たまにこんなことも起きます。

- **🌟 大漁タイム**（5 投のあいだ）… アタリが速くなり、レアも出やすくなる
- **👑 ヌシの気配**（次の 1 投）… レア以上しか掛からない

### アニメーション

canvas に直接描いています（外部ライブラリなし）。

- 空・水の色が時間帯で変わり、雲・星・カモメ・水草・光条・泡がそれぞれの速さで動く
- キャストしたルアーは放物線を描いて飛び、着水でしぶきと波紋が広がる
- アタリでウキが沈み、画面が小さく揺れて「！」が飛び出す
- ファイト中は竿がしなり、ラインが張って震え、水中では魚影が走る。ライン負荷が高いと画面が揺れる
- 釣り上げると魚が回転しながら水面から跳ね、きらめきと一緒に手元へ。釣果カードがポップインする
- 売るとコインが弾け飛び、所持金がカウントアップする
- 釣り場ごとに水の色が変わり、渓流には流れと岩、漁港にはテトラとカモメ、
  南の島には白い砂と椰子の木、深海には発光するプランクトンが出る
- 氷上の湖は一面が凍っていて、糸を落とす穴が開き、雪がちらつく。
  地底湖は空の代わりに岩の天井と鍾乳石があり、しずくが落ち、水晶が明滅する
- 天気で場面が変わる。雨と雪は空にだけ降り、水面に跡が残る。霧は白くかすみ、
  嵐では画面が暗くなって稲妻が走る

`prefers-reduced-motion` が有効な環境では CSS のアニメーションを止めています。

```
fishing/index.html          画面のマークアップ
fishing/src/engine.js       魚の抽選・値段・寄せの判定・持ち物（DOM 非依存。Node からも読める）
fishing/src/scene.js        canvas の描画とアニメーション
fishing/src/ui.js           進行と DOM の操作
fishing/src/style.css       スタイル

fishing/icons/              アプリのアイコン（元データは icon.svg）
```

中身を更新したときは `fishing/sw.js` の `CACHE` の版を上げると、古いキャッシュが捨てられます。

バランス調整や魚の追加はそこだけ触れば済みます。乱数も差し替え可能（`pickFish(spot, { rng })`）です。

```

npm run test:browser:fishing   # 実ブラウザで 3 匹釣って売って買うところまで通す（要 Playwright）
npm run test:mobile            # iPhone / iPad 相当の画面で、指だけで遊べるか・
                               # 機内モードでも起動するかまで通す（要 Playwright）
```

## 戦国 天下統一（歴史シミュレーション）

`sengoku/index.html` を開くと遊べます。1560 年（桶狭間の戦いの年）の日本で 19 家の大名から
ひとつを選び、ほかの大名家をすべて滅ぼして天下を統一するゲームです。
地図は本物の日本の地形をマス目にしたもので、約 130 の城がそれぞれ領地を持ちます（大きな国には本城と支城）。
マスごとに田や町を育てて城を豊かにします。
武将は約 1,150 人。ひとりひとりに自動生成の顔絵がつきます。
『信長の野望』のような国取りゲームを、ブラウザだけで手軽に遊べるようにしました。
こちらもビルド不要・依存パッケージなしで、進み具合は自動でブラウザに保存されます。

### 流れ

1. **大名を選ぶ**。★が多いほど難しい家です（尾張一国の織田家は ★★★）。
2. あなたの番。地図で自分の領地をクリックすると、その城にいる武将と命令が出ます。
   **ひとつの城につき月 3 回まで**命令できます（武将ひとりは月 1 回）。
3. 命令を使い切ったら右上の **月を終える**。CPU の番になって 18 家の大名が動き（合戦などが順に表示されます）、
   そのあと次の月のあなたの番が始まり、月報で何が起きたかわかります。
4. 隣の国へ **出陣** して城の兵を 0 にすれば落城。捕らえた武将は家臣に誘えます。
5. ほかの大名家がすべて滅ぶと天下統一。自分の国をすべて失うと負けです。

### 命令

| 命令 | 内容 |
| --- | --- |
| 🌾 開墾 | マスを選んで田を作る、または田のレベルを上げる。田が多いほど 9 月の米の収穫が増える（金 30〜70。森を切り開くと +15） |
| 🏘️ まちづくり | マスを選んで町を作る、または町のレベルを上げる。町が多いほど毎月の金の収入が増える（金 30〜70） |
| 🏯 築城 | 城の防御を上げる。守るときに強い（金 40） |
| 🪖 徴兵 | 金で兵を集める。統率が高いほど多く集まるが、民忠が少し下がる |
| ⚔️ 訓練 | 兵の訓練度を上げる。金はかからない |
| 🍙 施し | 米を配って民忠を上げる。民忠が低いと一揆が起きる（米 150） |
| 🐎 移動 | 隣の自分の国へ武将と兵を移す |
| 🔥 出陣 | 隣の他国へ攻め込む。兵 100 人につき米 5 が必要。率いられる兵は身分で決まる |
| 🔍 探索 | 国の中に隠れている在野の武将を探し、家臣に誘う（金 20） |
| 🎁 親善 | 他の大名に贈り物をして友好を上げる（金 60） |
| 🤝 同盟 | 友好 60 以上の大名と 24 か月の同盟を結ぶ。同盟中は互いに攻められない（金 150） |

### マス目の地図と土地

- 地図は都道府県の地形データから作った **194 × 82 マス**（陸は約 5,000 マス）。日本列島が横に寝るように 30 度回してあります。
  ドラッグで動かし、＋／－・ホイール・ピンチで拡大縮小できます。
- **城は 131**。旧国に近い 70 ほどの国（薩摩・大隅・日向・筑前・筑後・豊前・…・津軽・陸奥）に分け、大きな国には
  本城のほかに支城を置いています（例：尾張は清洲城と犬山城、武蔵は河越・江戸・鉢形・岩付）。
  各マスは同じ国の中でいちばん近い城の領地になり、領地が接している城どうしが「隣接」です（海路もあります）。
- 城ごとに兵・武将・民忠・訓練・命令（月 3 回）を持ち、攻め合いも城単位です。城の一覧は `sengoku/tools/castles.py` にあります。
- マスの地形は **平地・森・山** の 3 種類。平地と森には **田** か **町** を作れます（山と城のマスには作れません）。
- 田と町は **レベル 1〜3**。国の農業は「10 + 田のレベル合計 × 8」、商業は「10 + 町のレベル合計 × 8」です。
  レベルが上がるほど 1 回の費用が高くなり、森を切り開くときは少し高くつきます。
- 新しい田や町は **城か、すでにある田・町の隣** にしか作れません。城下から少しずつ広げていきます。
- 地形は標高データがないので、海からの距離と主な平野の位置から決めています（`sengoku/tools/build-map.py`）。

### 合戦

出陣すると合戦の画面になり、1 合戦ずつ「攻撃する」か「退却する」かを選びます。
攻め手・守り手とも **兵数 × 訓練度 × 大将の能力（統率 6 : 武勇 4）** が戦力で、
守り手はさらに城の防御ぶん有利になります。10 合戦で落とせなければ引き上げです。
出陣の前に「戦力の見立て（有利／互角／不利）」が出るので、目安にしてください。

落城すると守っていた武将は隣の自国へ逃げるか、捕虜になります。捕虜は「家臣に誘う」か「解放する」かを選べます。
当主を捕らえられた家は家督が継がれ、国も武将もなくなった家は滅亡します。滅んだ家の家臣は在野になります。

### 武将と身分

- 武将は **約 1,150 人**（`sengoku/src/generals.js`）。各家の家臣のほか、空白地の国人衆や浪人が「在野」として各地にいます。
- 能力は **統率**（合戦・徴兵）・**武勇**（合戦）・**政治**（内政・外交）の 3 つ。
- **身分**は 足軽頭（兵 1,500 まで）→ 侍大将（3,000）→ 部将（5,000）→ 家老（8,000）。当主は 12,000 まで率いられます。
  内政や合戦で**功績**がたまると自動で昇進します。
- 史実で 1560 年にまだ幼かった武将（伊達政宗、真田信繁、石田三成、立花宗茂など約 240 人）は**登場年**になると現れます。
  家が残っていれば仕官し、滅んでいれば在野になるので、探索で見つけて家臣にできます。
- **顔絵**は名前と能力から自動で描きます（`sengoku/src/portrait.js`）。肌の陰影・目のハイライト・毛の線を描き込んだ劇画ふうで、
  同じ武将はいつでも同じ顔。武勇が高いと兜（前立てつき）や太い眉、政治が高いと烏帽子が出やすく、
  年配の武将はしわや白髪が出ます。当主の絵は金の枠つきです。

### 金と米

- **金**は毎月、商業に応じて入ります（各城の商業 × 0.4）。
- **米**は 9 月に農業に応じて収穫され（各城の農業 × 20、豊作・凶作で増減）、毎月兵が食べます（兵 25 人につき 1）。
  米が尽きると兵が逃げ出すので、兵を増やしたら開墾も忘れずに。
- **民忠**が 25 未満だと一揆が起き、30 未満だと徴兵できません。

灰色の国は大名のいない **空白地** で、国人衆が守っています。大名の国より落としやすいので最初の狙い目です。

### CPU

CPU の大名は家ごとに毎月「いちばん落としやすい隣国」を狙いと決め、前線の国に兵を集めてから攻めます。
攻めるのは自分の戦力が相手の 1.3 倍以上あるときだけで、最初の 1 年はプレイヤーに少しだけ手加減します。
国ごとの 3 回の命令は、戦なら統率・武勇、内政なら政治の高い武将に任せ、徴兵・開墾・商業・築城・施し・探索・訓練を状況に応じて選びます。

### 構成

```
sengoku/index.html          画面のマークアップ
sengoku/src/data.js         城（131）の持ち主と初期値・大名（19 家）・身分のデータと定数
sengoku/src/generals.js     武将（約 1,150 人）のデータ
sengoku/src/mapdata.js      マス目の地図（tools/build-map.py が自動生成。手で直さない）
sengoku/src/land.js         マスの田・町のルール（作れる場所・費用・農業/商業の計算）
sengoku/src/engine.js       命令の実行・合戦・身分と功績・探索・月の進行（DOM 非依存。Node からも読める）
sengoku/src/ai.js           CPU 大名の思考
sengoku/src/map.js          マス目の日本地図の描画（canvas。ドラッグ・拡大縮小）
sengoku/tools/castles.py    城の一覧（id・城名・国・緯度経度）と海路
sengoku/tools/build-map.py  都道府県の地形データ（GeoJSON）から mapdata.js（領地・隣接・地形）を作るスクリプト
sengoku/src/portrait.js     武将の顔絵の自動生成（SVG）
sengoku/src/ui.js           進行と DOM の操作・自動保存
sengoku/src/style.css       スタイル
sengoku/test/engine.test.js エンジンと CPU の単体テスト（34 件）
sengoku/test/browser.smoke.mjs 実ブラウザでの通し確認（Playwright、任意）
```

城の持ち主と初期値・大名は `sengoku/src/data.js`、城の位置は `sengoku/tools/castles.py`、武将は `sengoku/src/generals.js` に
1 人 1 行（名前・家・国・統率・武勇・政治・登場年）で並んでいるので、史実に合わせて手直ししたり、
武将を増やしたりするときはそこだけ触れば済みます。

地図を作り直すときは、[dataofjapan/land](https://github.com/dataofjapan/land) の `japan.geojson` を用意して
`python3 sengoku/tools/build-map.py japan.geojson sengoku/src/mapdata.js` を実行します（Python 3 だけで動きます）。
回転の角度、マスの細かさ、平野の位置はスクリプトの先頭で変えられます。城を増やすときは `castles.py` に
1 行足して（id・城名・国・経度・緯度）スクリプトを回すと、領地と隣接が付け直されます。
乱数は保存データに入った整数から作るので、続きから遊んでも同じ結果になります。

```
npm test                       # 上の 4 つのゲームのテストをまとめて実行
npm run test:browser:sengoku   # 実ブラウザで大名を選び、内政 → 出陣 → 月送り → 続きから、まで通す（要 Playwright）
node sengoku/tools/bundle.mjs  # 1 ファイル版 sengoku/dist/sengoku.html を作る（サーバーなしで開ける・配布用）
```
