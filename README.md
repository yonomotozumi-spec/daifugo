# 大富豪（大貧民）

ブラウザだけで遊べる大富豪です。CPU 3 人と対戦できます。
ビルド不要・依存パッケージなしの素の HTML + ES Modules なので、`index.html` を開けばそのまま動きます。

```
git clone https://github.com/yonomotozumi-spec/daifugo.git
cd daifugo
npx --yes http-server . -p 8080   # または python3 -m http.server 8080
# → http://localhost:8080 を開く
```

ES Modules を使っているため、`file://` で直接開くとブラウザに読み込みを拒否されます。
上のように簡易サーバー経由で開いてください。

同じリポジトリに釣りゲーム **[のんびり釣り日和](fishing/)**（`http://localhost:8080/fishing/`）も入っています。
スマホ・タブレットではホーム画面に追加してアプリとして遊べます。画面右上のリンクで行き来できます。
→ [遊びかたはこちら](#のんびり釣り日和釣りゲーム)

## 遊びかた

- カードをクリックして選び、**出す**。出せないときは **パス**。
- **ヒント** を押すと CPU と同じ思考ルーチンがおすすめの手を選んでくれます。
- キーボード：`Enter` で出す、`P` でパス、`Esc` で選択解除。
- 3 人があがった時点でラウンド終了。大富豪 3pt / 富豪 2pt / 貧民 1pt / 大貧民 0pt が加算されます。

## 対応しているルール

右上の **ルール設定** から個別に ON / OFF できます（設定はブラウザに保存されます）。

| ルール | 内容 |
| --- | --- |
| 革命 | 同ランク 4 枚、または 5 枚以上の階段で強さが逆転する。もう一度出せば元に戻る |
| 8 切り | 8 を含む手を出すと場が流れ、同じ人がそのまま親になる |
| 縛り | 同じスートが 2 回続くと、その場はそのスートしか出せなくなる |
| 階段 | 同じスートの 3 枚以上の連番を出せる |
| スペ3返し | ジョーカー 1 枚に対して ♠3 で勝てる |
| カード交換 | 2 ラウンド目以降、大富豪⇔大貧民で 2 枚、富豪⇔貧民で 1 枚を交換する |

その他の基本ルール:

- カードの強さは 3 < 4 < … < K < A < 2 < ジョーカー。
- ジョーカーはワイルドカードとして、同ランクの組にも階段の穴埋めにも使えます。
  ただし階段の**両端**には使えません（5-6-7 とも 6-7-8 とも読めてしまうため）。
- 場が空のときはパスできません。全員がパスすると場が流れ、最後に出した人が親になります。
- 初回の親は ♦3 を持っている人、2 ラウンド目以降は前回の大貧民です。

未実装のルール：都落ち、反則あがり、ジョーカー 2 枚出しの特別扱い、5 人以上での対戦。

## 構成

```
index.html          画面のマークアップ
src/engine.js       ルールエンジン（DOM 非依存。Node からも読める）
src/ai.js           CPU の思考ルーチン
src/ui.js           描画とイベント処理
src/style.css       スタイル
test/engine.test.js エンジンの単体テスト（node:test、依存なし）
test/browser.smoke.mjs 実ブラウザでの通し確認（Playwright、任意）
```

ルール判定は `src/engine.js` に閉じています。役の解釈は `parseCombo()`、
場に出せるかの判定は `canPlay()`、進行は `Game` クラスが持っています。
乱数は差し替え可能（`new Game({ rng })`）なので、シードを固定すれば同じ配牌を再現できます。

## テスト

```
npm test            # エンジンの単体テスト 22 件。依存パッケージなし
```

CPU 同士で 5 シード × 5 ラウンドを自動対戦させ、非合法手が出ないこと・
必ずラウンドが終わることも通しで確認しています。

ブラウザでの動作確認（任意、Playwright が必要）:

```
npx --yes http-server . -p 8123 &
npm i -D playwright && npx playwright install chromium
node test/browser.smoke.mjs      # test/screenshots/ に画面写真が出ます
```

## のんびり釣り日和（釣りゲーム）

`fishing/index.html` を開くと遊べます。魚を釣って売り、そのお金で竿・ルアー・釣り場を買いそろえていくゲームです。
大富豪とは独立していて、こちらもビルド不要・依存パッケージなしです。

### 流れ

1. **キャスト** して、ウキが沈むのを待つ
2. アタリが来たら **合わせる**（早すぎても遅すぎても逃げられます）
3. **寄せのミニゲーム**：長押しで寄せバーを上げ、離すと落ちる。魚をバーに入れ続けると寄ってくる
4. 釣れたら **売る** か **逃がす**（逃がしても図鑑の記録は残ります）
5. 貯めたお金でショップから道具を買い、もっと大物が釣れる釣り場へ

操作はスペースキー（キャスト／合わせ／長押しで巻く／売る）、`S` でショップ、`Z` で図鑑。
画面のどこをクリック・タップしても同じように操作できます。所持金と図鑑はブラウザに保存されます。

### スマホ・タブレットで遊ぶ（アプリとして追加する）

ブラウザで開いてホーム画面に追加すると、アドレスバーのない全画面のアプリとして起動します。
ストアからの入手は不要で、**通信が切れても遊べます**（釣果もそのまま残ります）。

- **iPhone / iPad（Safari）**：共有ボタン → 「ホーム画面に追加」。
  画面右上の <kbd>⬇️</kbd> を押すと、この手順が絵つきで出ます。
- **Android（Chrome）**：右上の <kbd>⬇️</kbd>、またはブラウザの「アプリをインストール」から。
- **PC（Chrome / Edge）**：アドレスバーのインストールアイコンから。

縦持ち・横持ち・タブレットのどれでも遊べるように組んでいます。

| 端末 | 画面 |
| --- | --- |
| スマホ（縦） | 釣り場が画面いっぱい。日誌は下から引き出す。所持金と釣り場だけ上に出す |
| スマホ（横） | 操作部を薄くして釣り場を広く取る |
| タブレット・PC | 右側に釣果と釣り日誌を並べた 2 段組 |

操作はすべて指だけで完結します（画面のどこでもタップでキャスト／合わせ、長押しで巻き上げ）。
アタリ・釣り上げ・ライン切れでは、対応する端末なら手元も震えます。

### そろえるもの

| 種類 | 内容 |
| --- | --- |
| 釣り竿 | パワー・寄せ速度・バーの広さ・ライン強度が上がる。竿より強い魚を掛けるとラインが切れる |
| ルアー・エサ | レアな魚の出やすさ、アタリの速さ、ゴミの釣れにくさが変わる。釣り場ごとの得意・不得意もある |
| 釣り場 | 池 → 渓流 → 海 → 深海。奥に行くほど高い魚が出るが、強い魚も掛かる |

魚は全 36 種。レア度は ふつう / めずらしい / レア / 超レア / 伝説 の 5 段階で、
同じ魚でも大きいほど高く売れます。キャストするたびに 朝 → 昼 → 夕 → 夜 と時間が進み、
夜ほどレアが出やすくなります。

### アニメーション

canvas に直接描いています（外部ライブラリなし）。

- 空・水の色が時間帯で変わり、雲・星・カモメ・水草・光条・泡がそれぞれの速さで動く
- キャストしたルアーは放物線を描いて飛び、着水でしぶきと波紋が広がる
- アタリでウキが沈み、画面が小さく揺れて「！」が飛び出す
- ファイト中は竿がしなり、ラインが張って震え、水中では魚影が走る。ライン負荷が高いと画面が揺れる
- 釣り上げると魚が回転しながら水面から跳ね、きらめきと一緒に手元へ。釣果カードがポップインする
- 売るとコインが弾け飛び、所持金がカウントアップする
- 釣り場ごとに水の色が変わり、渓流には流れと岩、深海には発光するプランクトンが出る

`prefers-reduced-motion` が有効な環境では CSS のアニメーションを止めています。

### 構成

```
fishing/index.html          画面のマークアップ
fishing/src/engine.js       魚の抽選・値段・寄せの判定・持ち物（DOM 非依存。Node からも読める）
fishing/src/scene.js        canvas の描画とアニメーション
fishing/src/ui.js           進行と DOM の操作
fishing/src/style.css       スタイル
fishing/manifest.webmanifest ホーム画面アプリとしての設定（PWA）
fishing/sw.js               オフラインで遊ぶための Service Worker
fishing/icons/              アプリのアイコン（元データは icon.svg）
fishing/test/engine.test.js エンジンの単体テスト（36 件）
fishing/test/browser.smoke.mjs 実ブラウザでの通し確認（Playwright、任意）
fishing/test/mobile.smoke.mjs  スマホ・タブレットでの通し確認（Playwright、任意）
```

アイコンを描き替えるときは `fishing/icons/icon.svg` を直してから PNG を焼き直します。
中身を更新したときは `fishing/sw.js` の `CACHE` の版を上げると、古いキャッシュが捨てられます。

魚・竿・ルアー・釣り場のデータはすべて `fishing/src/engine.js` の先頭の配列に並んでいます。
バランス調整や魚の追加はそこだけ触れば済みます。乱数も差し替え可能（`pickFish(spot, { rng })`）です。

```
npm test                       # 大富豪 22 件 + 釣り 36 件
npm run test:browser:fishing   # 実ブラウザで 3 匹釣って売って買うところまで通す（要 Playwright）
npm run test:mobile            # iPhone / iPad 相当の画面で、指だけで遊べるか・
                               # 機内モードでも起動するかまで通す（要 Playwright）
```
